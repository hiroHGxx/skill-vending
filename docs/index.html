Agent Skillsの自動販売機

skill-vending

Claude の Agent Skills を、会話の中で探して入れられる
読み取り専用 MCP サーバー

なにができるか

Claude Code にこの MCP サーバーを繋ぐと、スキルの検索からインストールまでが会話だけで完結します。

「議事録系のスキルない？」 → 検索 → 内容を全文確認 → ~/.claude/skills/ へ保存

スキルの実体はすべて GitHub リポジトリにあり、サーバーはそれを読むだけ（read-only）です。

導入手順

Node.js 18 以上と Claude Code が必要です。以下を実行するだけです：

claude mcp add skill-vending -- npx -y github:hiroHGxx/skill-vending

または .mcp.json に追記：

{
  "mcpServers": {
    "skill-vending": {
      "command": "npx",
      "args": ["-y", "github:hiroHGxx/skill-vending"]
    }
  }
}
