# AIっぽさのパターン集と修正例

## 1. 定型フレーズ（検出したら原則除去・置換）

| ❌ AIっぽい表現 | ✅ 修正方針 |
|---------------|-----------|
| 〜と言えるでしょう／〜ではないでしょうか | 断定するか削る：「〜です」「〜だと思います」 |
| いかがでしたか？ | 削除（読者への丸投げ。締めは内容で書く） |
| 〜することができます | 「〜できます」 |
| 〜という形になります／〜という形です | 「〜になります」「〜です」 |
| 重要なポイントは〜です | 前置きを削り、ポイント自体を最初に書く |
| 結論から言うと | （実際に結論を先に書いていれば不要。削る） |
| 〜を活用することで | 「〜を使うと」「〜で」 |
| 〜が可能です | 「〜できます」 |
| 〜において／〜における | 「〜で」「〜の」 |
| 〜を行う | 具体的な動詞に：「検証を行う」→「検証する」 |
| 近年、〜が注目されています | 具体的な事実か自分の観察に置き換える |
| ぜひ試してみてください | 文脈に合う具体的な次の一歩に置き換えるか削る |

## 2. 構成の癖

### 網羅癖・「3つのポイント」構成

- 症状：聞かれていない観点まで「メリット・デメリット・注意点」と律儀に並べる
- 修正：主張に必要な項目だけ残す。バランスを取るための「一方で〜」は、本当に対立軸が重要なときだけ

### 不要な箇条書き

- 症状：2〜3項目しかない、または項目間に順序・並列関係がない内容のリスト化
- 修正：散文に戻す。「AとBの2つがあります」で足りる内容に箇条書きは不要

### まとめ癖

- 症状：1000字未満の文章に「まとめ」「おわりに」セクション。直前に書いたことの言い直し
- 修正：まとめを削除し、最後の段落を締めの一文に差し替える

### 見出しの過剰使用

- 症状：数段落ごとに見出し。見出しだけ読むと本文が不要になる
- 修正：話題が本当に切り替わる箇所だけに見出しを残す

## 3. 文体・リズムの癖

### 均質な文末

- 症状：「〜です。〜です。〜です。」「〜ます。〜ます。」の連続
- 修正：3文に1回程度、文末を変える（体言止め／「〜でしょう」／短文）。ただし体言止めの多用は逆に不自然

### 均質な文長

- 症状：全文が40〜60字で揃っている
- 修正：短い文を混ぜる。「違います。」「ここが肝心です。」のような5〜10字の文が入るとリズムが生まれる

### 過剰な接続詞

- 症状：ほぼ全文が「さらに」「また」「そして」「加えて」「一方で」で始まる
- 修正：接続詞の7割は削っても文意が通る。削って通るものはすべて削る

### 過剰なヘッジ（保険）

- 症状：「一般的には」「場合によっては」「〜かもしれません」「〜と考えられます」の多用
- 修正：本当に不確実な箇所だけ残し、あとは断定する。全文ヘッジは責任回避に見える

### 漢語の過剰使用

- 症状：「実施する」「活用する」「構築する」「実現する」が1段落に複数回
- 修正：和語に開く：「実施する」→「やる・行う」、「構築する」→「作る」、「活用する」→「使う」

## 4. 内容面の癖（「内容面の提案」として分けて提示するもの）

- **具体例の不在**：抽象論が続く場合、書き手自身の体験・数字を入れる提案をする（創作はしない）
- **一般論の再生産**：誰でも書ける内容になっている場合、書き手の意見・立場を明示する箇所を提案する
- **読者想定のブレ**：初心者向けの説明と専門用語が混在している場合、どちらかに寄せる提案をする

## 修正例（Before / After）

**Before（AIっぽい）**：

> 近年、リモートワークが注目されています。リモートワークを活用することで、通勤時間を削減することができます。さらに、集中できる環境を構築することが可能です。一方で、コミュニケーションが不足する場合もあるかもしれません。重要なポイントは、自分に合った働き方を見つけることだと言えるでしょう。

**After（自然）**：

> リモートワークに切り替えて2年になります。通勤がなくなって1日90分浮きました。集中もしやすい。ただ、雑談が減ったせいで仕事の相談のハードルは上がった気がします。結局、向き不向きの問題です。

修正内容：定型フレーズ5箇所を除去、「近年〜注目」を具体的な事実に置換、ヘッジ2箇所を断定に変更、文長に変化を追加。※ After の「2年」「90分」のような具体値は創作せず、書き手に確認して埋めること。
