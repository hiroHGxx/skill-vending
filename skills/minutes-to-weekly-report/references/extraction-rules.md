# アクションアイテム抽出ルール

## 基本原則

1. **創作禁止**：議事録に書かれていない担当者・期限・内容を推測で補わない。不明は「未定」
2. **1タスク1行**：複数の作業が1文に含まれる場合は分割する（例：「AとBを確認」→ 2行）
3. **決定事項と区別**：すでに決まったこと（結論）はアクションではない。週報の「実施事項」側に回す

## 担当者の特定

| 議事録の記述例 | 抽出結果 |
|--------------|---------|
| 「田中：〜をお願いします」 | 田中さん |
| 「〜は佐藤さん対応」 | 佐藤さん |
| 「営業チームで検討」 | 営業チーム |
| 「各自確認しておく」 | 全員 |
| 担当の記載なし | 未定 |

- 敬称は「さん」で統一する（役職名が明記されている場合は「〇〇部長」等そのまま使用可）
- 同一人物の表記ゆれ（フルネーム／苗字のみ）は最初に登場した表記に統一する

## 期限の正規化

| 議事録の記述例 | 変換ルール |
|--------------|-----------|
| 「8/20までに」 | 2026/08/20（年は会議日付から補完） |
| 「今週中に」 | 会議日の週の金曜日に換算し「※換算」と注記 |
| 「来週中に」 | 翌週金曜日に換算し「※換算」と注記 |
| 「次回会議までに」 | 次回日程が明記されていればその日付、なければ「次回会議まで」 |
| 「月末までに」 | 当月末日に換算し「※換算」と注記 |
| 期限の記載なし | 未定 |

- 会議日付が議事録から特定できない場合は、相対表現をそのまま残す（「今週中」等）
- 換算した期限には必ず「※〜より換算」の注記を付け、原文の表現が分かるようにする

## 暗黙のアクションを示すシグナル表現

以下の表現が出たら、アクションアイテム候補として検討する：

- 「持ち帰り」「持ち帰って検討」→ 検討結果の報告タスク
- 「確認しておく」「確認が必要」→ 確認タスク
- 「調整する」「調整中」→ 調整タスク（完了報告まで含む）
- 「宿題」「TODO」「AI（Action Item）」→ 明示的なアクション
- 「〜の方向で」「〜する想定」→ 決定事項寄り。実作業が伴う場合のみアクション化

## 状態の初期値

- 議事録時点で着手済みと明記されているもの → 「進行中」
- それ以外 → 「未着手」
