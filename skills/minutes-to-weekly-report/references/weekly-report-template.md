# 週報テンプレート

以下のテンプレートに従って週報を作成する。セクションの追加・削除・並び替えはしない。
該当する内容がないセクションは「特になし」と記載する。

```markdown
# 週報（YYYY/MM/DD 〜 YYYY/MM/DD）

**氏名**：〇〇
**所属**：〇〇部 〇〇チーム

## 1. 今週の実施事項

- （完了したこと・決定したことを箇条書き。各項目は体言止めまたは「〜しました」で統一）

## 2. 来週の予定

- （アクションアイテムのうち直近のもの。「〜を実施予定」の形で記載）

## 3. 課題・相談事項

- （懸念・保留・上長への相談事項。相談事項には「【相談】」を先頭に付ける）

## 4. 所感

- （任意。1〜3行程度。事実と意見を区別して記載）
```

## 記載ルール

- 文体は「です・ます」調。箇条書き内は体言止め可
- 1項目1行を原則とし、長くなる場合はサブ項目に分ける
- 数値・日付は具体的に書く（「順調です」ではなく「進捗80%、8/20完了見込みです」）
- ネガティブな報告こそ具体的に書く（遅延の場合：現状・原因・リカバリ案の3点セット）
- 「所感」以外に主観的な表現（「頑張りました」等)を入れない

## 週の期間の決め方

- 議事録の会議日付を含む週（月曜〜金曜）を対象期間とする
- 会議日付が不明な場合は、期間をプレースホルダー「YYYY/MM/DD 〜 YYYY/MM/DD」のまま残し、ユーザーに確認する
