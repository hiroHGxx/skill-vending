# 類型別テンプレートと注意点

すべて社外向けの例。社内向けの場合は宛名を「〇〇さん」、挨拶を「お疲れ様です。」に差し替え、敬語レベルを一段下げる。

## 1. 依頼

```
件名：【ご依頼】〇〇資料ご提供のお願い（△△株式会社・氏名）

〇〇株式会社
〇〇部 〇〇様

いつもお世話になっております。
△△株式会社の〇〇です。

〇〇の件につきまして、□□の資料をご提供いただきたく、
ご連絡いたしました。

【依頼内容】〇〇
【希望期日】YYYY年MM月DD日（〇）
【背景】〇〇のため

お忙しいところ恐れ入りますが、ご対応いただけますと幸いです。
期日のご都合が難しい場合は、遠慮なくお知らせください。

何卒よろしくお願いいたします。

（署名）
```

注意点：期限は必ず具体日付＋曜日。依頼内容が複数ある場合は箇条書きで分離。

## 2. お詫び

```
件名：【お詫び】〇〇の納期遅延について

（宛名・挨拶・名乗り）

このたびは、〇〇の納期に遅れが生じ、
多大なご迷惑をおかけしましたことを深くお詫び申し上げます。

【経緯】（事実を簡潔に。言い訳をしない）
【原因】（判明している範囲で）
【今後の対応】新しい納期：YYYY年MM月DD日（〇）
【再発防止策】（具体的に）

改めまして、このたびの件、誠に申し訳ございませんでした。
今後ともご指導のほど、よろしくお願い申し上げます。
```

注意点：謝罪を最初に置く。原因説明が言い訳に聞こえる書き方（「〜のせいで」）を避ける。対応と再発防止をセットで示す。

## 3. 催促

```
件名：【ご確認】〇〇のご回答について（MM/DD期日分）

（宛名・挨拶・名乗り）

MM月DD日にお送りしました〇〇の件につきまして、
その後のご状況はいかがでしょうか。

行き違いでご対応いただいておりましたら、
大変失礼いたします。

〇〇の都合上、MM月DD日（〇）までにご回答いただけますと
大変助かります。

お忙しいところ恐れ入りますが、ご確認のほど
よろしくお願いいたします。
```

注意点：最初の送信日を明記。責める表現（「まだですか」「ご放念でしょうか」）は使わない。新しい期限を提示する。

## 4. お礼

```
件名：〇〇のお礼（△△株式会社・氏名）

（宛名・挨拶・名乗り）

このたびは〇〇いただき、誠にありがとうございました。

（具体的に何が助かったか・どう活きたかを1〜3行）

今後ともどうぞよろしくお願いいたします。
```

注意点：お礼は当日〜翌営業日に送るのが望ましい旨をユーザーに伝える。具体性のない「いろいろありがとうございました」を避ける。

## 5. 報告・連絡

```
件名：【ご報告】〇〇の対応完了について

（宛名・挨拶・名乗り）

〇〇の件、本日対応が完了しましたのでご報告いたします。

【対応内容】
【結果】
【今後の予定・お願い事項】（あれば）

ご不明点がございましたら、お気軽にお問い合わせください。
```

注意点：結論（完了／未完了／変更）を必ず1行目に。相手に求めるアクションの有無を明示する。

## 6. お断り

```
件名：〇〇のご提案について

（宛名・挨拶・名乗り）

このたびは〇〇をご提案いただき、誠にありがとうございました。

社内で慎重に検討いたしました結果、誠に恐縮ながら、
今回は見送らせていただくこととなりました。

（理由を1〜2行。詳細に立ち入りすぎない）

せっかくのご提案に沿えず心苦しい限りですが、
何卒ご了承いただけますと幸いです。

またの機会がございましたら、その際はどうぞ
よろしくお願いいたします。
```

注意点：感謝 → 結論 → 簡潔な理由 → 今後への含み、の順を守る。断る理由を詳しく書きすぎると反論の余地を与える。
