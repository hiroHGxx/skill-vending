# 敬語ルール

## 基本の対応表（よく使う動詞）

| 普通形 | 尊敬語（相手の動作） | 謙譲語（自分の動作） |
|--------|-------------------|-------------------|
| する | なさる | いたす |
| 言う | おっしゃる | 申し上げる |
| 見る | ご覧になる | 拝見する |
| 聞く | お聞きになる | 伺う・拝聴する |
| 行く | いらっしゃる | 伺う・参る |
| 来る | いらっしゃる・お越しになる | 参る |
| いる | いらっしゃる | おる |
| 知る | ご存じ | 存じる・存じ上げる |
| もらう | お受け取りになる | いただく・頂戴する |
| 食べる | 召し上がる | いただく |
| 読む | お読みになる | 拝読する |
| 会う | お会いになる | お目にかかる |

**大原則**：相手の動作には尊敬語、自分（自社）の動作には謙譲語。取り違えが最も多い誤りです。

## よくある誤用と修正例

| ❌ 誤用 | ✅ 修正 | 理由 |
|--------|--------|------|
| 資料を拝見してください | 資料をご覧ください | 「拝見」は謙譲語。相手の動作に使えない |
| おっしゃられる | おっしゃる | 二重敬語（尊敬語＋れる） |
| お伺いさせていただきます | 伺います | 二重敬語＋させていただく過剰 |
| ご持参ください | お持ちください | 「持参」は謙譲語 |
| 了解しました（目上へ） | 承知いたしました・かしこまりました | 「了解」は対等以下向け |
| ご苦労様です（目上へ） | お疲れ様です | 「ご苦労様」は目下向け |
| とんでもございません | とんでもないことでございます／恐れ入ります | 「とんでもない」で一語 |
| 弊社の部長がおっしゃった | 弊社の部長が申し上げた | 社外に対して自社側は謙譲 |
| 〜になります（断定） | 〜でございます・〜です | 変化を伴わない「なります」は誤用 |
| お名前を頂戴できますか | お名前を伺えますか | 名前は「もらう」ものではない |

## 「させていただく」の使用基準

「させていただく」が適切なのは、**相手の許可**や**相手からの恩恵**が前提にある場合のみ：

- ✅ 「（お許しが出たので）本日は休業させていただきます」
- ✅ 「（ご依頼を受けて）見積もりを送付させていただきます」
- ❌ 「弊社は東京で創業させていただきました」（許可・恩恵の相手がいない）

多用すると慇懃無礼な印象になるため、**1通のメールで2回まで**を目安とし、「いたします」で言い換えられる箇所は言い換える。

## クッション言葉（依頼・断り・催促の前置き）

| 場面 | クッション言葉の例 |
|------|------------------|
| 依頼 | お忙しいところ恐れ入りますが／お手数をおかけしますが |
| 質問 | 差し支えなければ／失礼ですが |
| 断り | 大変心苦しいのですが／せっかくのお申し出ですが／あいにくですが |
| 催促 | 行き違いでしたら申し訳ございませんが／ご確認の行き違いでしたらご容赦ください |
| 反論・指摘 | 恐れながら／僭越ながら |

## 社内メールの敬語レベル

- 社内は「です・ます」調＋最小限の敬語でよい。過剰な謙譲語はかえって距離を作る
- 宛名は「〇〇さん」または「〇〇部長」（役職＋様は重複しない。「部長様」は誤り）
- 挨拶は「お疲れ様です。」が標準
